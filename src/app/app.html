Forms built around a writable signal model

Signal Forms use a writable signal as the source of truth. Angular creates a field tree from that model, and the [formField] directive connects fields to native inputs or custom controls.

01

Model

signal() stores the current form data.

02

Field tree

form() creates typed field access from the model.

03

Schema

Validation and conditional rules describe field behaviour.

04

Binding

FormField keeps the UI and model synchronized.
